# 🛡 Digital Forensics & CTF Practice Repository

This repository documents hands-on digital forensics and cybersecurity challenges completed to strengthen investigative and analytical skills.

The focus areas include:
- Metadata analysis
- Log investigation
- File signature verification
- Encoding & decoding techniques
- File reconstruction
- PowerShell & Linux command-line forensics

Each writeup follows a structured approach:
1. Objective
2. Observations
3. Hypothesis
4. Investigation Steps
5. Evidence
6. Real-world relevance

The goal of this repository is to build practical DFIR (Digital Forensics & Incident Response) skills and develop structured investigative thinking.
